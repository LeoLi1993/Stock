# 半导体行业

半导体全产业链：上游原材料→晶圆制造→封装测试→下游终端

## 工艺流程
-    拉硅棒：通过半导体单晶硅棒拉晶设备，通过加热炉把多晶硅加热融化，放入一块籽晶往上拉把凝固的单晶硅大棒
-    硅棒研磨：通过晶棒磨床把硅棒外表面研磨，使得其表明光滑
-    切硅片：利用金刚石进行切割，形成一个一个的圆形硅片。
-    研磨：通过CMP研磨设备对硅片进行研磨，到达预期的厚度
-    清洗抛光：把硅片放入化学溶剂中清晰从而去除表明杂质，用机械对硅片进行抛光
-    IC晶圆制造之氧化：为了避免污染我们需要对其表明进行氧化，形成一层薄薄二氧化硅
-    涂胶：往晶圆上面图上光刻胶，一层绝缘体，避免导电影响其他设备（难点是光刻胶这种物质）
-    光刻：利用特殊光线通过特定图形对光刻胶进行照射会进行化学反应，从而在光刻胶上面形成相应的图案。
-    显影：通过显影液对光刻胶进行化学反应，溶解成我们期待的图形，之后通过高温烘干使得光刻胶粘的更牢固，显影是在光刻胶上面挖坑。
-    刻蚀：把光刻胶上面的图形刻到芯片里面，刻蚀是在硅片上挖坑把二氧化硅通过化学反应去掉。
-    去胶：利用化学试剂把晶圆上面没用的光刻胶去除掉
-    离子注入：把离子注入到晶圆里面去
-    退火： 修复被离子注入破坏的晶格结构，把晶圆加热到一定温度并以恒定速度冷却从而修复晶格缺陷
-    薄膜沉积： 芯片堆叠的地基，会在晶圆表面形成一层薄膜，在薄膜基础之上做电路
-    金属化：通过前面的沉积和刻蚀已经形成了一些器件，现在需要把这些器件连接起来，形成金属导线的过程就是金属化
-    晶圆剪薄：通过设备把晶圆背面磨薄
-    切片：把晶圆切成一个一个小的芯片
-    晶圆贴片：把前面的一个一个小的芯片通过胶水和底座贴合
-    引线键合：把底脚和芯片焊接起来，使得芯片之间可以通信
-    芯片封装：把计算芯片，存储芯片和通信等芯片整合在一起，外面套个谁生产的壳子
-    芯片测试：温度测试，能耗测试，
-    清洗：
     -    湿式：氢氟酸，盐酸，过氧化氢，氢氧化铵，硫酸和水进行清洗。这个占大多数。还有二流体清洗，通过兆生波或者氮气清洗。
     -    干式：二氧化碳，臭氧或者等离子气体把表明杂质吹掉


## 上游材料

```
高纯多晶硅：工业硅提纯→电子级多晶硅（99.9999999% 纯度）
特种金属 / 化合物：铜、铝、钛、钨、锗、砷化镓、碳化硅、氮化镓（第三代半导体基材）
高纯化学试剂 / 气体：电子特气、高纯酸碱、有机溶剂
```

高纯多晶硅 → 电子级多晶硅：**通威股份， 协鑫科技**

特种半导体材料：硅 / 锗 / 碳化硅 / 氮化镓 -> **天岳先进、露笑科技、三安光电**

## 硅片制造

单晶硅棒拉制：**晶盛机电（设备）、沪硅产业（硅片）**

切片 / 打磨 / 抛光 → 抛光硅片（8/12 英寸）: **沪硅产业**（12 英寸量产龙头）、**中环股份、立昂微**（8 英寸主力）
