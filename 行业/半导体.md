# 半导体行业

半导体全产业链：上游原材料→晶圆制造→封装测试→下游终端

基础原料：

## 上游材料

```
高纯多晶硅：工业硅提纯→电子级多晶硅（99.9999999% 纯度）
特种金属 / 化合物：铜、铝、钛、钨、锗、砷化镓、碳化硅、氮化镓（第三代半导体基材）
高纯化学试剂 / 气体：电子特气、高纯酸碱、有机溶剂
```

高纯多晶硅 → 电子级多晶硅：**通威股份， 协鑫科技**

特种半导体材料：硅 / 锗 / 碳化硅 / 氮化镓 -> **天岳先进、露笑科技、三安光电**

## 硅片制造

单晶硅棒拉制：**晶盛机电（设备）、沪硅产业（硅片）**

切片 / 打磨 / 抛光 → 抛光硅片（8/12 英寸）: **沪硅产业**（12 英寸量产龙头）、**中环股份、立昂微**（8 英寸主力）



## 上游配套材料

 光刻胶（g/i 线 → KrF → ArF → EUV）: **南大光电（ArF）、彤程新材、晶瑞电材**

掩膜版（光罩）: **清溢光电、中芯国际**

电子特气: **华特气体、金宏气体、雅克科技**

湿电子化学品（清洗 / 蚀刻）：**江化微、晶瑞电材、格林达**

 CMP 抛光液 / 抛光垫：**安集科技（液）、鼎龙股份（垫）**

 高纯靶材（铝 / 铜 / 钛 / 钨）：**江丰电子、有研新材、阿石创**



## 上游核心设备（卡脖子重灾区）

光刻机：**上海微电子（SMEE）**

刻蚀机（干法 / 湿法）：中微公司（介质刻蚀）、北方华创（导体刻蚀）

薄膜沉积（CVD/PVD/ALD）：**北方华创（PVD/CVD）、拓荆科技（PECVD）、微导纳米（ALD）**

离子注入机： **凯世通（万业企业）、中科信**

 清洗设备：**盛美上海、至纯科技、北方华创**

CMP 设备： **华海清科**

涂胶显影设备：**芯源微**

量测 / 检测设备：**中科飞测、精测电子、万业企业**



## 中游前段：芯片设计（EDA/IP→RTL→版图）

EDA 软件：**华大九天（全流程）、概伦电子、广立微**

IP 核（CPU / 接口 / 模拟）： **芯来科技（RISC-V）、平头哥、紫光展锐**

芯片设计（Fabless/IDM）

- 存储：**长鑫存储（DRAM）、长江存储（3D NAND）、兆易创新（NOR）**
- 逻辑：**海光（CPU/DCU）、寒武纪、紫光展锐、瑞芯微**
- 模拟 / 功率：**圣邦股份、卓胜微、斯达半导、士兰微**



## 中游核心：晶圆厂制造（光刻→刻蚀→沉积→注入→抛光）

晶圆代工：**中芯国际（14nm 量产、N+2≈7nm）、华虹半导体、积塔半导体**

## 中游后段：封装测试

封装设备（划片 / 键合 / 塑封）：**光力科技（划片）、长川科技（测试）、新益昌（固晶）**

封装服务（传统 + 先进）：**长电科技（全球第 3）、通富微电、华天科技、晶方科技**

测试设备：**长川科技、华峰测控、精测电子**

## 下游：终端组装 & 应用

终端产品（手机 / PC / 服务器 / 汽车 / 工业）:**华为、小米、联想、浪潮、比亚迪、宁德时代**



```
一句话总览（替代梯度）
第一梯队（基本自主）：硅片（8 寸）、多晶硅、g/i 线光刻胶、成熟制程封测、终端组装
第二梯队（加速替代）：刻蚀、沉积、清洗设备、靶材、电子特气、KrF 光刻胶、成熟制程代工、模拟 / 功率 / MCU 设计
第三梯队（卡脖子、攻坚中）：光刻机（DUV/EUV）、ArF/EUV 光刻胶、高端掩膜版、离子注入机、量测设备、全流程 EDA、先进制程（≤7nm）代工、高端 CPU/GPU/AI 芯片
```
